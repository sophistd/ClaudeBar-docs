# ClaudeBar documentation

An English, static documentation site for ClaudeBar's macOS network egress,
session isolation, diagnostics, and recovery workflows. ClaudeBar is independent
and is not affiliated with or endorsed by Anthropic.

## Develop

Use Node.js 24 and npm. The lockfile is authoritative.

```sh
npm ci
npm run dev
```

Open `http://localhost:4321/ClaudeBar-docs/`. Search is generated by the production
build; use `npm run build` and `npm run preview` to check it.

## Verify

```sh
npm run verify
npx playwright install chromium
npm run test:browser
```

This checks content types, the lifecycle teaching model, production generation,
local links and anchors, publication-sensitive patterns, and browser workflows.
Browser checks include search, copy, themes, mobile navigation, overflow, and
automated accessibility rules. Automated tests do not certify full WCAG compliance.

## Content model

`src/content/docs/` is the canonical MDX source. Each page declares audience,
purpose/type, prerequisites, expected outcome, and evidence status. Raw Markdown
and `llms.txt` are generated from the same collection. English is the root locale;
future translations can use Starlight's locale model.

## Publish

The intended standalone repository is `sophistd/ClaudeBar-docs`. It contains only
the reviewed documentation files, never the application repository's history,
internal notes, binaries, credentials, or local diagnostic data.

Generate an exact disclosure manifest with `node scripts/publication.mjs`.
Obtain the owner's authorization for that file set before the first public push.
Enable GitHub Pages with **GitHub Actions** as the source. The workflow validates
pull requests and publishes approved main changes. Its repository identity check
prevents accidental execution inside the private application repository.

Site origin and base path live in `astro.config.mjs`; update and verify both if the
destination changes. A workflow file is not proof that deployment succeeded.
Verify the live homepage, a deep route, search, and raw Markdown after publication.
