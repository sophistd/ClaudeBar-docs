ClaudeBar is an independent native macOS utility for **network egress control, session isolation, environment diagnostics, and recovery**. Its menu bar offers a quick status view; its workbench holds configuration, evidence, and recovery actions.

## How the pieces fit

<div class="flow" role="img" aria-label="A profile configures a local gate; the gate controls managed sessions."><span>Profile<br/>Route and session settings</span><b aria-hidden="true">→</b><span>Local gate<br/>Verified route and lifecycle</span><b aria-hidden="true">→</b><span>Managed session<br/>App or supported browser</span></div>

A profile describes the intended setup. Diagnostics collect observations. The gate uses a verified baseline to decide whether to admit managed connections. Recovery checks whether that baseline still holds.

## Know the boundary

A green state means the gate currently permits connections; it may be using a previously verified baseline without a new observation. Check the diagnostic record for fresh evidence. It is not a guarantee for all applications, all traffic, or provider account outcomes. Read [security boundaries](/ClaudeBar-docs/concepts/security/) before relying on a configuration.

These docs describe a reviewed source baseline, not a promise of public binary availability. Begin with [installation and access](/ClaudeBar-docs/start/installation/). ClaudeBar is not affiliated with or endorsed by Anthropic.
