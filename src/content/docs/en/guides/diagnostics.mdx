## Collect a current observation

Open **Checks & repair** (**检查与修复**) from a risk alert on the workbench Launchpad; the app also opens it when the check before a launch fails. Review the active profile, then use **全量扫描** (full scan) to rerun checks. The CLI equivalent is:

```sh
swift run claudebar-cli probe --json
```

This is a live operation: it can contact network endpoints, access profile credentials, and update local diagnostic records. Run it intentionally in your configured environment. It is not the offline setup check.

## Interpret the status

| Status | Meaning | Next action |
| --- | --- | --- |
| PASS | The observed check met its predicate | Continue, within that check's scope |
| MITIGATED | A compensating control covers the finding; the underlying condition may remain | Read which control provides coverage |
| FAIL | An observed condition did not meet the predicate | Fix the stated cause and rerun |
| UNOBSERVED | Evidence was not obtained | Resolve reachability or collection problems |
| SKIPPED_BLOCKED | A prerequisite blocked execution | Address the prerequisite first |

Severity is separate from status. A critical failure or an uncovered critical observation gap can block the gate.

## Trace cause before changing settings

Read the expected condition and the actual observation. Check whether you are looking at the current profile, a historical incident, or a session outside the managed launch path. Then inspect the proposed repair and its scope.

The diagnostic pipeline orders prerequisite checks before downstream provider checks. A skipped downstream check is not proof that the provider is healthy or unreachable.

## Share evidence carefully

The export command produces an agent-oriented diagnostic bundle:

```sh
swift run claudebar-cli export-bundle ./diagnostics.claudeguard.zip
```

Export also performs live evaluation. The exporter applies redaction, but you must inspect the archive before sharing it. Do not upload raw account information, proxy credentials, or private session content. See [security boundaries](/ClaudeBar-docs/concepts/security/).
