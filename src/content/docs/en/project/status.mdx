## Documentation baseline

Building on the initial **November 17, 2026** source review, this edition was updated against the source baseline reviewed on **November 22, 2026** (covering Gecko browser sandboxes, `H17` cross-profile same-engine risk detection, `P19` read-only CLI `userID` and Desktop `ant-did` binding audits, optional `blockDatacenterASN` fail-closed enforcement, and the live Protection Receipt card). These dates are source-review dates, not a versioned application release announcement.

## Evidence ledger

| Area | Evidence | Limit |
| --- | --- | --- |
| Platform and package targets | Manifest inspected | Not a tested OS/architecture matrix |
| Gate lifecycle and recovery | State-machine code and fixture tests inspected, including multi-source country split, IP drift, and grace recovery | Not full-system validation across every network topology |
| Browser modes and cross-profile risk | Four-tier browser engine models (pure Chromium / Gecko / wrapped shell / WebKit), `H17` overlap analysis, and `P15` / `P19` audits inspected with fixture tests | Real long-lived multi-browser and multi-account sessions not externally certified |
| CLI build, help and offline parsing | CLI product built; help and a credential-free loopback parse succeeded | No live proxy credentials or routing changes tested |
| Diagnostic and repair commands | Implementations and redaction export logic inspected | Live diagnostics and state-changing commands not run here |
| System extension and packaging | Source and scripts exist | Activation, signing and notarization not tested here |

These checks use controlled fixtures in a local environment. They do **not** prove account immunity from provider restrictions or whole-device traffic containment.

## Still unverified

Public application downloads, a supported release matrix, and independent full-system security validation are not established. Documentation deployment status belongs to the actual Pages run.

## Illustrated evidence

The [illustrated guide](/ClaudeBar-docs/concepts/visual-guide/) connects three mechanism diagrams to four native interface screenshots. The screenshots were rendered from actual SwiftUI views by the application's existing perceptual regression suite: 25 view checks passed. Network states, scores, and timings are test fixtures; this is not evidence of a live account session or a real network check.
