## Start with four objects

| Object | Question it answers | What it is not |
| --- | --- | --- |
| Profile | Which configuration should this session use? | A provider account or a guarantee of isolation |
| Gate | May this managed connection use the verified route now? | An automatic whole-device VPN |
| Session | Which app or browser instance is using that configuration? | Every window already running on the Mac |
| Observation | What did a particular check actually see? | A permanent certificate of network health |

## The operating loop

Configure a profile, gather observations, verify the route, launch a managed session, and review new evidence when conditions change. The workbench separates an overview from checks and repairs, incident history, egress history, and settings.

ClaudeBar also contains prompt-preflight tooling. That is a separate workflow: configured cloud stages may transmit supplied text to a selected model provider. It is not required to learn network session management.

## Evidence language

**Implemented** means a source path supports the behavior. **Verified** means a stated check was actually executed with a recorded result. **Planned** means an intention without an implemented, verified delivery. These states are not interchangeable.
