## ClaudeBar 是 Anthropic 的产品吗？

ClaudeBar 是独立项目，与 Anthropic 无隶属关系，也未获其背书。

## 用了 ClaudeBar 就能保证不被封号吗？

不能。ClaudeBar 负责管住本机受管出口、本地目录隔离与启动前后核验，但管不住代理节点本身的机房/脏 IP 属性、同浏览器内核的硬件与图形指纹重合、支付卡/Stripe Radar、邮箱与手机号关联、Persona/Yoti 身份核验，以及 Sift 全网信誉图谱。详见[保护范围与数据安全](/ClaudeBar-docs/zh/concepts/security/)。

## 为什么不能用同一个 Chrome 开多个 Profile 登多号？为什么不做指纹伪装？

在同一个 Chrome 里建多 Profile 或多沙箱，只隔开了 Cookie，Web 端 Sift 采集的约 74/79 项硬件与图形渲染特征仍然相同，既存在连坐风险，也会直接触发 `users_per_device_id` 主动计数加分。同时，ClaudeBar 刻意不做 JS 指纹伪装，也不屏蔽 `s-cdn.anthropic.com`，以免反篡改校验或信标缺失引发更大异常。单机多账号应按“一机一号 > 隔离 CLI > 跨浏览器内核（一核一号）”的阶梯安排，详见[多账号隔离与风控边界](/ClaudeBar-docs/zh/guides/multi-account-isolation/)。

## 它能当通用 AI 智能体工作台用吗？

ClaudeBar 的主要用途是管理 macOS 上的受管网络出口、隔离会话，以及诊断和恢复连接。

## 装上之后，本机所有应用都会自动受到保护吗？

本机回环门禁只管接入它的受管连接。可选的系统级控制需要单独部署。现有证据未验证整台设备的防护能力，覆盖范围见[保护范围与数据安全](/ClaudeBar-docs/zh/concepts/security/)。

## 文档里的界面截图从哪里来？

[图解导读](/ClaudeBar-docs/zh/concepts/visual-guide/)中的截图由应用已有的截图测试渲染，使用的是实际 SwiftUI 界面。网络状态、分数和耗时采用测试样例；总览里的浏览器名称来自渲染机器的运行列表。截图用于说明界面，并不证明真实网络或账号会话已经通过验证。机制配图和门禁交互则是帮助理解的教学示意。

## 去哪里下载应用？

应用源码是私有的，本站仅提供文档。获取源码权限或构建包的方式见[安装与访问](/ClaudeBar-docs/zh/start/installation/)。

## 哪里能看项目路线图？

当前文档记录已经实现的行为和待验证的事项。内部工程计划由项目另行管理，公开承诺以项目明确发布的信息为准。可以在[源码基线与验证记录](/ClaudeBar-docs/zh/project/status/)查看现有进展。

本次核对的源码基线未发现公开的软件许可证。文档可公开阅读；软件使用和分发的许可条款需向维护者确认。
