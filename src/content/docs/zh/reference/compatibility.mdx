## 系统与工具链

软件包声明支持 macOS 14 或更高版本，Swift tools version 为 6.2。编写文档时，在 Apple 芯片 Mac 上使用 Swift 6.4.2 成功构建了 CLI，选取的 25 项测试也通过了。Intel Mac 和不同 macOS 版本的运行情况尚未验证。

## 浏览器可用模式

| 浏览器 | 实现支持的模式 | 使用条件 |
| --- | --- | --- |
| Chrome、Edge、Brave（标准 Chromium） | 单独打开（受控沙箱）、原生会话 | 具体能力以本机安装检测为准 |
| Arc、Dia、Aside（基于 Chromium 且有自有封装） | 原生会话 | Chromium 启动参数和独立数据目录未必可用 |
| Safari（WebKit） | 原生会话 | 无法通过 Chromium 命令行参数设置路由 |

原生会话由浏览器自己决定怎么联网，ClaudeBar 不注入代理。只有检测到已安装的浏览器支持子配置档案时，才能按子配置档案路由。表格依据当前实现，各浏览器版本的实际运行情况未逐一验证。

## 代理协议能否接入门禁

以下格式均可解析；能否直接联网取决于接入条件。

| 导入格式 | 接入门禁的条件 |
| --- | --- |
| HTTP CONNECT | 核验通过后，门禁可直接使用该代理，无需本地桥接 |
| SOCKS5 / SOCKS5H | 走 SOCKS 连接 |
| HTTPS 上游代理 | 需要本地桥接服务。门禁不会静默降级 TLS |
| Shadowsocks、VMess、VLESS、Trojan、Hysteria2、TUIC 分享格式 | 远端加密传输需要本地代理内核做桥接 |
| Clash YAML 中受支持的条目 | 取决于解析出的协议 |

本地桥接服务需要另行配置，并在回环地址上运行。ClaudeBar 的解析器不会替你安装第三方代理内核。

## 系统扩展和包过滤

源码包含系统扩展。本地构建之后，仍需取得 macOS 所需的权限并激活扩展。包过滤也需要提升权限，控制的是系统网络层，普通回环监听只处理连到本地端口的流量。本次文档验证期间，系统扩展和包过滤均未启用或测试。
