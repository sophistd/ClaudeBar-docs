## 系统与工具链

软件包声明支持 macOS 14 或更高版本，Swift tools version 为 6.2。文档核对期间在 Apple 芯片 Mac 上验证了构建与受控测试套件；Intel Mac 和不同 macOS 大版本的运行情况尚未逐一验证。

## 浏览器可用模式与内核族

| 浏览器内核档位 | 常见浏览器 | 实现支持的模式 | 指纹族与使用条件 |
| --- | --- | --- | --- |
| 纯 Chromium | Chrome、Edge、Brave、Aside | 单独打开（受控沙箱）、原生会话 | `chromium` 族；具体能力以本机安装检测为准。同族多 Profile 或多沙箱仅隔离 Cookie，不隔离硬件与渲染指纹 |
| Gecko 独立内核 | Firefox、Zen（动态识别含 LibreWolf、Waterfox、Floorp） | 单独打开（受控沙箱）、原生会话 | `gecko` 族；通过 `-no-remote -profile` 与 `user.js` 隔离。与 Chromium 跨内核可减少浏览器安装级指纹重叠 |
| Chromium 外壳封装 | Arc、Dia | 原生会话 | 同属 `chromium` 族；不支持标准 Chromium 独立目录与启动参数 |
| 系统 WebKit | Safari | 原生会话 | `webkit` 族；无法通过 Chromium 命令行参数设置路由 |

原生会话由浏览器自己决定怎么联网，ClaudeBar 不注入代理。只有纯 Chromium 档且检测到子配置档案时，才支持按子配置档案确定性路由。单机若需登录多个不同 Web 账号，请按不同指纹族分配（如 Chrome 搭配 Firefox / Zen），详见[多账号隔离与风控边界](/ClaudeBar-docs/zh/guides/multi-account-isolation/)。

## 代理协议能否接入门禁

以下格式均可解析；能否直接联网取决于接入条件。

| 导入格式 | 接入门禁的条件 |
| --- | --- |
| HTTP CONNECT | 核验通过后，门禁可直接使用该代理，无需本地桥接 |
| SOCKS5 / SOCKS5H | 走 SOCKS 连接 |
| HTTPS 上游代理 | 需要本地桥接服务。门禁不会静默降级 TLS |
| Shadowsocks、VMess、VLESS、Trojan、Hysteria2、TUIC 分享格式 | 远端加密传输需要本地代理内核做桥接 |
| Clash YAML 中受支持的条目 | 取决于解析出的协议 |

本地桥接服务需要另行配置，并在回环地址上运行。ClaudeBar 的解析器不会替你安装第三方代理内核。

## 系统扩展和包过滤

源码包含系统扩展。本地构建之后，仍需取得 macOS 所需的权限并激活扩展。包过滤也需要提升权限，控制的是系统网络层，普通回环监听只处理连到本地端口的流量。本次文档验证期间，系统扩展和包过滤均未启用或测试。
