## 配置档案字段

以下字段来自当前配置档案模型，存储格式尚未作为稳定的外部 JSON 接口提供。请通过应用或已记录的 CLI 命令修改配置，避免在应用运行时手动编辑存储文件。

| 字段 | 默认值或范围 | 用途 |
| --- | --- | --- |
| `name` | 必填 | 配置档案的显示名称 |
| `proxyConfig` | 必填 | 规范化后的上游代理设置 |
| `strictIPPinning` | `true` | 开启固定 IP 后，恢复时须匹配出口基线中的 IP |
| `blockDatacenterASN` | `false` | 开启后将 `P05` 机房/商业 VPN ASN 检查升格为 `CRITICAL` Fail-Closed，命中机房或 ASN 缺测均阻断放行 |
| `graceDurationMs` | `4000` 毫秒，限制在 `1000–10000` 毫秒 | 恢复宽限期 |
| `telemetryMode` | `proxiedPassThrough` | 受管会话的遥测处理方式 |
| `browserBinding` | 省略时根据所选浏览器推导 | 记录浏览器应用、会话模式及可选的浏览器子配置档案 |
| `freezeProcessGroupDuringGrace` | `false` | 是否在宽限期内暂停进程组 |
| `isolateClaudeConfigDir` | 传统单档案模型默认 `false`；多通道档案默认 `true` | 是否为配置档案分配独立 `CLAUDE_CONFIG_DIR`（隔离 CLI `~/.claude.json` `userID`） |
| `configRevision` | 至少为 `1` | 用版本号区分配置变更 |

底层门禁 API 的宽限期可从 200 毫秒起设。通过配置档案设置时，以表中的范围为准。

## 上游代理设置

规范化后的代理配置记录传输协议、上游主机和端口、可选用户名、钥匙串凭据引用、可选的固定出口国家和 IP，以及区域和时区。未指定区域和时区时，初始化默认使用 `en-US` 和 `America/Los_Angeles`。这两个值来自程序设定，请按目标使用环境填写。

模型会过滤敏感的协议元数据。密码请通过应用支持的凭据流程保存，避免写入 JSON。导入成功后，还要查对应的[协议接入条件](/ClaudeBar-docs/zh/reference/compatibility/)。

## 遥测模式

| 值 | 行为和验证范围 |
| --- | --- |
| `proxiedPassThrough` | 默认值。不注入隐私相关环境变量，受管流量（含 `s-cdn.anthropic.com` 风控信标）全部走同一锁定出口转发 |
| `officialPrivacyFlags` | 加入隐私相关环境变量，由门禁拦停配置后缀匹配的第三方遥测（如 Sentry / Datadog / Segment）；**不会**拦截 `s-cdn.anthropic.com`，风控信标仍与主站同源转发 |
| `enterpriseCloudProvider` | 已定义此配置值。该枚举值不会额外注入环境变量，云服务商链路的端到端行为尚未验证 |

关于账号结果与风控边界，见[保护范围与数据安全](/ClaudeBar-docs/zh/concepts/security/)与[多账号隔离与风控边界](/ClaudeBar-docs/zh/guides/multi-account-isolation/)。
