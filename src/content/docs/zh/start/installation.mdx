## 从哪里拿到应用？

请向项目维护者获取授权版本。应用源码在私有仓库里，仓库权限由维护者提供。此文档站仅提供使用说明，目前没有随这版文档开放应用下载。

## 安装前检查 Mac 和网络

- Mac 运行 **macOS 14 或更高版本**。这是 Swift 包声明的最低系统版本。
- 从源码构建时，准备 **Swift 6.2** 或兼容工具链。
- 使用受管连接时，准备可访问的上游代理。
- 使用浏览器会话时，先安装所选模式支持的浏览器。

如果要用系统扩展功能，还需要对应的 entitlement、签名、配置描述文件和 macOS 批准，并确保相应部署正在运行。普通 SwiftPM 构建完成后，这些部署条件仍需单独确认。

## 如果维护者给你的是 DMG

源码包含 DMG 打包与发布自动化。安装前向维护者核实文件来源、版本、公证状态、适用机型及安装说明。打开磁盘映像，按说明把应用放进「应用程序」，然后启动。按 macOS 的安全提示操作。若系统拦下来源尚未核实的版本，保留安全检查，先核实版本。

应用启动后，继续[完成首次配置](/ClaudeBar-docs/zh/start/first-setup/)。

## 如果你有源码权限

按[构建与测试](/ClaudeBar-docs/zh/developers/build/)操作。CLI 产物和部分使用测试样例的用例已在本地 Swift 6.4.2 工具链上验证。完整的发布、打包和各环境安装组合仍待验证，范围见[基线与验证状态](/ClaudeBar-docs/zh/project/status/)。
