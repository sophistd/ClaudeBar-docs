## 从哪里下载公证版安装包？

当前最新公开版本为 **ClaudeBar v0.6.0**（macOS 14+，Apple Silicon，已通过 Developer ID 签名与 Apple 公证，应用源码仓仍保持私有）：

- **直接下载 DMG**：[ClaudeBar-0.6.0.dmg](https://github.com/sophistd/ClaudeBar-docs/releases/download/v0.6.0/ClaudeBar-0.6.0.dmg)（约 11 MB）
- **发布页与更新记录**：[GitHub Release v0.6.0](https://github.com/sophistd/ClaudeBar-docs/releases/tag/v0.6.0)
- **SHA-256 校验值**：`3110148e8047f10b88dfca535e69b42ede1b4cdbac3ec115ce406122967913c3`

安装步骤：打开下载好的 DMG，将 `ClaudeBar.app` 拖入「应用程序」文件夹后启动即可。从 **v0.6.0** 起，后续新版本可在应用内 **设置 → 通用 → 软件更新** 手动点击「下载并更新」，自动校验 SHA-256 与 Apple 公证签名后一键重启替换。

## 安装前检查 Mac 和网络

- Mac 运行 **macOS 14 或更高版本**。这是 Swift 包声明的最低系统版本。
- 从源码构建时，准备 **Swift 6.2** 或兼容工具链。
- 使用受管连接时，准备可访问的上游代理。
- 使用浏览器会话时，先安装所选模式支持的浏览器。

如果要用系统扩展功能，还需要对应的 entitlement、签名、配置描述文件和 macOS 批准，并确保相应部署正在运行。普通 SwiftPM 构建完成后，这些部署条件仍需单独确认。

## 如果维护者给你的是 DMG

源码包含 DMG 打包与发布自动化。安装前向维护者核实文件来源、版本、公证状态、适用机型及安装说明。打开磁盘映像，按说明把应用放进「应用程序」，然后启动。按 macOS 的安全提示操作。若系统拦下来源尚未核实的版本，保留安全检查，先核实版本。

应用启动后，继续[完成首次配置](/ClaudeBar-docs/zh/start/first-setup/)。

## 如果你有源码权限

按[构建与测试](/ClaudeBar-docs/zh/developers/build/)操作。CLI 产物和部分使用测试样例的用例已在本地 Swift 6.4.2 工具链上验证。完整的发布、打包和各环境安装组合仍待验证，范围见[基线与验证状态](/ClaudeBar-docs/zh/project/status/)。
