## 打开一个会话，要确认哪四件事？

| 你要确认什么 | 去哪里看 |
| --- | --- |
| 这次用哪条线路、哪个浏览器？ | **配置档案**（Profile）保存这一组设置。账号登录情况和能否隔离，要到实际会话里确认。 |
| 受管连接现在能走这条线路吗？ | **门禁**按核验结果决定是否放行。控制范围限于受管连接。 |
| 哪个应用或浏览器实例正在使用这组设置？ | 看此次启动的**会话**。Mac 上原来打开的窗口可能属于别的会话。 |
| 这次检查实际看到了什么？ | 看**观测结果**。它反映检查当时的情况，线路变化后要看新的结果。 |

工作台里可以看总览、检查与修复、事件复盘、出口历史和设置。网络条件变了，到对应页面看最新观测，再决定怎么处理。

ClaudeBar 还有发送前检查提示词的功能。这是单独的流程。配置云端处理步骤后，输入的文本可能会发给选定的模型提供方。管理网络会话时可以跳过这项功能。

## 文档里的「已实现」「已验证」和「计划中」

- **已实现**：源码里有支撑这个行为的实现。
- **已验证**：实际跑过指定检查，并记录了结果。
- **计划中**：已有意向，实现和验证尚未交付。

[基线与验证状态](/ClaudeBar-docs/zh/project/status/)记录了这版文档覆盖的范围。手上已有授权版本，可以直接[完成首次配置](/ClaudeBar-docs/zh/start/first-setup/)。需要获取应用时，先看[安装与获取](/ClaudeBar-docs/zh/start/installation/)。
