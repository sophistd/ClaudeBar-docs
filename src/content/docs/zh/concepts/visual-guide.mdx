## 上游中断后，门禁怎么决定是否恢复

<DocFigure src="/ClaudeBar-docs/diagrams/recovery-zh.svg" alt="已放行门禁进入宽限期。出口匹配则恢复，观测到漂移则立即隔离，到期按是否记录到探测拒绝处理。" width={780} height={330} lang="zh" />

图中的「沿用旧基线」不等于重新核验出口。

配置档案的默认宽限期是 4 秒，等待的是新握手。旧隧道能否保留取决于中断原因。网络切换或系统休眠可以立即断开旧隧道，普通的上游短时中断可以保留旧隧道。可用[门禁交互演示](/ClaudeBar-docs/zh/concepts/network-egress/)分别试一次。


## 去 macOS 界面里找入口

以下为应用界面截图，使用固定的演示数据，不代表实时网络状态。截图中菜单栏面板和工作台侧栏显示的是英文标签，下文在括号里给出中文界面的对应名称。

### 菜单栏面板

首次使用时，面板顶部按「Proxy / Apps / Arm」（通道 / 入口 / 放行）提示进度。点右上角的 **Detect Proxy**（嗅探代理）查找本机代理，或点提示卡去 Channels 绑定一条通道。点底部 **Workbench**（工作台）进入完整界面。

<DocFigure src="/ClaudeBar-docs/screenshots/menu-panel-firstrun-light.png" alt="首次使用时的菜单栏面板：顶部是 Proxy / Apps / Arm 三步进度和 Detect Proxy 按钮，中间提示先接入一条本机代理通道，底部有 Workbench、Settings 和 Quit。" width={712} height={388} kind="screenshot" lang="zh" />

### 启动台

工作台侧栏有 **Launchpad**（启动台）、**Channels**（通道）和 **Preflight**（发前预检），底部是当前通道切换和 **Settings**（偏好设置）。有异常、门禁已隔离或有未读事件时，侧栏会多出 **Incidents**（待处置）。

在启动台先看主通道那张通关卡：通道名、本机监听地址、检查通过数和放行状态。再看「我的受控入口」，每个已纳管的桌面应用或浏览器各占一行，从这里打开。

<DocFigure src="/ClaudeBar-docs/screenshots/workbench-overview-light.png" alt="启动台：顶部是 US-Primary 主通道的通关卡，标为已放行、检查 22/22；下方「我的受控入口」列出 Claude Desktop、Google Chrome、Safari、Dia、Aside 五个入口，各带打开按钮。" width={2080} height={1360} kind="screenshot" lang="zh" />

### 检查与修复

「检查与修复」不在侧栏常驻。启动台上出现风险提醒时，点它会跳到这里，并定位到那条风险关系。启动前的核验没有通过时，应用也会打开这一页。

先读顶部四张卡：出口、检查、同一出口、风险。再从左侧「风险关系」找到已触发的条目，每条都写明是哪几项检查触发的，到右侧「22 项检查」里按编号查看。右侧可按 L1–L5 分层筛选。具体怎么读，见[诊断结果](/ClaudeBar-docs/zh/guides/diagnostics/)。

<DocFigure src="/ClaudeBar-docs/screenshots/workbench-topology-light.png" alt="检查与修复页面处于失步状态：顶部四张卡显示出口 HK、检查 19/22 通过、11 个端点同一出口、3 项风险；左侧风险关系列出 3/17 条已触发，右侧 22 项检查按 L1–L5 分层，P01、P03 未过。" width={2080} height={1360} kind="screenshot" lang="zh" />

### 内容预检

侧栏的 **Preflight** 打开「内容预检」。它检查输入文本，与网络启动前检查是两个流程。启用云端阶段时，文本可能发送给模型服务商。

<DocFigure src="/ClaudeBar-docs/screenshots/workbench-preflight-light.png" alt="内容预检页面：上方是 S0 分词到 S3 语义、最后判定的分析阶段；左侧为示例原文和消歧改写、复制净本按钮；右侧风险向量场把命中词连到风险类别。" width={2080} height={1360} kind="screenshot" lang="zh" />
