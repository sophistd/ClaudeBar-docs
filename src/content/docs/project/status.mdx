## Documentation baseline

This site describes the application source baseline reviewed on **November 17, 2026**. It is not a versioned application release announcement. Source review covered the Swift package, CLI dispatch, gate lifecycle, profile and browser models, diagnostic/export paths, UI labels, and existing tests.

## Evidence ledger

| Area | Evidence | Limit |
| --- | --- | --- |
| Platform and package targets | Manifest inspected | Not a tested OS/architecture matrix |
| Gate lifecycle and recovery | State-machine code and test cases inspected | 12 selected gate and tunnel tests passed; not full-system validation |
| Browser modes and bindings | Models, scanner and CLI inspected | 6 browser-isolation model tests passed; real browser/account sessions not exercised |
| CLI build, help and offline parsing | CLI product built; help and a credential-free loopback parse succeeded | No live proxy credentials or routing changes tested |
| Diagnostic and repair commands | Implementations inspected | Live diagnostics and state-changing commands not run |
| System extension and packaging | Source and scripts exist | Activation, signing and notarization not tested here |

The application checks used Swift 6.4.2: **25 tests across four suites** passed, covering gate recovery, transparent tunnels, browser isolation, and proxy parsing. These fixtures do not establish real account sessions, every network topology, or the complete application suite.

## Still unverified

Public application downloads, a supported release matrix, and independent full-system security validation are not established. Documentation deployment status belongs to the actual Pages run.

## Illustrated evidence

The [illustrated guide](/ClaudeBar-docs/concepts/visual-guide/) connects three mechanism diagrams to four native interface screenshots. The screenshots were rendered from actual SwiftUI views by the application’s existing perceptual regression suite: 25 view checks passed. Network states, scores, and timings are test fixtures; this is not evidence of a live account session or a real network check.
